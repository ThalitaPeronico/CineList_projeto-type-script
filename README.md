# CineList_projeto-type-script
Um sistema simples para gerenciar listas de filmes ou séries (Para Assistir / Assistidos) e registrar avaliações pessoais.

## Funcionalidades

- Cadastro e login com senha criptografada
- Adicionar, ver, editar e excluir filmes/séries
- Cada usuário gerencia sua própria lista (título, tipo, gênero, status, avaliação e observações)

## Instalação

Requer [Node.js](https://nodejs.org/) 22 ou superior.

```bash
git clone https://github.com/ThalitaPeronico/CineList_projeto-type-script.git
cd CineList_projeto-type-script
npm install
```

## Uso

```bash
npx tsx index.ts
```

Ao iniciar, você cria uma conta ou faz login. Depois, um menu permite adicionar, ver, editar e excluir itens da sua lista.
